# iOS Rank Monitor Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this approved plan task by task. Execution is already authorized by the user; do not request another planning approval.

**Goal:** Deliver a repository-scoped Codex skill that collects Qimai iPhone category rankings and maintains local, portable reports without conversation memory.

**Architecture:** Codex controls the local browser. A Python standard-library program validates visible-page snapshots, persists runs, compares adjacent formal runs, and renders offline reports. GitHub distributes code and instructions; real data and credentials stay local.

**Tech Stack:** Python >=3.11, standard library only; native HTML/CSS/JavaScript.

**Spec:** The behavior contract is recorded in README.md and config/monitor.json.

## Global Constraints
- US, DE, JP; iPhone; 24 app categories and 16 game categories; free and grossing top 80.
- Asia/Shanghai daily 02:00, 06:00, 12:00, 18:00.
- Either chart newly entering top 80 qualifies; country/family/category/app deduplication.
- Compare the immediately previous formal run, including failed runs; absent snapshots mean unknown, never zero or an older fallback.
- All real data and generated outputs under ignored data/; all credentials and lock state under ignored .local/.
- No external runtime packages; no hardcoded personal paths or browser handles; no publishing real data.

## Review Focus
- Partial/failed runs must not disappear from the comparison chain.
- Completed snapshots must match the requested scope and ranks 1..80.
- Crash recovery must not create a duplicate run or steal an active lock.
- Copying a data directory must preserve relative links and run ordering.
- Untrusted names/URLs must not become HTML or unsafe links.
