# 每榜单最近有效完整快照比较

依据：用户确认每个榜单向前寻找最近有效完整数据，不设回溯期限，标明实际跨度；同步技能和任务，保持启停状态，历史报告不重算。

1. 新配置及新轮次使用 `comparisonVersion: latest_valid_scope_v1`。缺少配置仍沿用 shared_scopes_v1；旧记录及导入保留旧比较方式。previousRunId始终表示上一执行轮次。
2. 每个范围从当前轮次之前的归档历史逆序寻找兼容完整前80；允许部分轮次和已有兼容旧快照，隔离正式/测试。缺数和不兼容范围跳过，没有兼容基准则建立该范围基线。本轮缺数不得填旧数据。存储损坏明确报错。
3. 登记后固化每范围基准编号、来源日期、采集时间、快照摘要、跨过轮数；manifest保存校验摘要。恢复/候选/日期/归档均复用，不自动重选。当前与基准采集时间之差为实际跨度。
4. 排名候选、双榜合并和六个月发布条件继续复用现有处理。HTML/Markdown/邮件展示各触发榜单基准和跨度，覆盖区分回溯、本轮缺数、无历史基准。只能说明两个端点差异，不能推断中间变化或首次入榜时刻。
5. 报告生成复用已封存report-data，不重算历史；已有单轮报告不重写，日期页仅有新增轮次或缺失产物时更新。邮件正文继续冻结，不自动补发。
6. 测试：多轮失败、不同范围不同基准、无期限、兼容跳过、缺数、损坏、冻结与恢复、双榜/日期、旧版本、历史文件与缓存变化、页面转义和邮件。运行完整测试集，独立审查后更新既有任务并核对设置与历史哈希。

审查重点：历史只读、运行链与比较基准分离、首次冻结崩溃恢复、基准文件缺失/修改、正式与测试隔离、双榜的独立跨度、旧报告不因新版本重算。
