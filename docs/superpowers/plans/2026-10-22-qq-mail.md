# QQ 邮箱本轮报告实施计划

依据：用户于 2026-10-22 确认的完整方案。正文列出全部已确认入选 App，名称链接七麦详情，零入选也发送摘要；不启动采集，不恢复暂停任务，不自动提交或推送。

1. 配置与预览：独立本地配置及 600 权限授权码，离线检查；独立 HTML/纯文本模板，沿用固化结果、数量口径，完整列表、分组和转义。先补失败测试，再实现。
2. 发送：仅封存正式浏览器轮次；独立锁、冻结正文、按收件人记账。成功不重发，提交后断线/中断标记结果不明，只有连接建立前的临时网络错误自动重试一次。30 秒连接超时，TLS 证书验证，不打印凭据。
3. 接入：新增 mail-check、mail-preview、mail-send；finalize/render/import 不自动发信。任务显式调用 mail-send，保留暂停状态、时间、项目和其他设置。
4. 验收：模拟 SMTP、内容和配置回归，完整 unittest；预览视觉检查；检查历史不可变文件。仅本机完成账号配置后向配置目标发送一次指定轮次验收邮件。

审查重点：多收件人部分成功、提交成功后本地写盘中断、模板/配置变更后的重复执行、秘密泄漏、未知数量不能变成确认零、历史重建不能发信。
