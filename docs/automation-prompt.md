# 定时任务设置

- 项目：目标Mac克隆的本仓库目录
- 运行：独立任务、本地项目目录
- 时间：Asia/Shanghai每天02:00、06:00、12:00、18:00

## 可直接复制的任务描述

读取当前仓库AGENTS.md，执行本仓库的 `$ios-rank-monitor`。先完成程序、浏览器和账号预检，再按仓库配置，通过本机内置浏览器采集七麦的美德日iPhone分类免费榜与畅销榜前80。每范围完成后立即保存，调用仓库程序完成严格相邻任务比较、存档和报告更新。缺数与首次基线标为待比较，不计为零，不回退更早历史。

必要时使用本地凭据正常登录七麦；遇验证码、短信/扫码、二次验证、风控或缺权限，记录需要人工处理，保留本轮失败记录。重复启动跳过时不干扰已有采集。不自行修改程序、配置或筛选规则。数据、凭据、日志、截图和报告仅本地保存，不提交、不推送、不发送到其他应用。

结束时更新Markdown日期总览和离线HTML筛选页，给出已确认新进数量、完整/可比较范围、失败原因及报告位置。程序和规则以本仓库版本为准，不依赖创建任务时的聊天历史。
